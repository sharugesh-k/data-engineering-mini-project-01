# Data Engineering Mini Project 01

## Overview
This project demonstrates a simple ETL (Extract, Transform, Load) pipeline using Python.

## Features
- Extract data from API
- Transform data using Python
- Load processed data into storage

## Technologies
- Python
- Pandas
- Requests

## Project Structure
extract.py
Transform.py
load.py
main.py

## How to Run

pip install -r requirements.txt
python main.py
